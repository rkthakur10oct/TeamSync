# TeamSync

A full-stack Team Collaboration and Project Management Platform built with Django REST Framework and React.

## 🚀 Features

- JWT Authentication
- User Registration & Login
- Team Management
- Team Join using UUID
- Role-based Team Members
- REST APIs
- PostgreSQL Database

## 🛠️ Tech Stack

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL

### Frontend
- React.js (Coming Soon)

## 📁 Project Structure

TeamSync/
├── backend/
└── frontend/

## ⚙️ Setup

```bash
git clone https://github.com/rkthakur10oct/TeamSync.git
cd TeamSync
```

Backend:

```bash
cd backend
python -m venv venv
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
